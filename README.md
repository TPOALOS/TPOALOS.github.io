# TPOALOS.github.io

The catalog site for [TPOALOS](https://github.com/TPOALOS)'s command-line tools: https://tpoalos.github.io/

`index.html`, `sitemap.xml` and `robots.txt` are generated from the live repository list:

```bash
python3 build.py        # needs the GitHub CLI (`gh`) to be logged in
```

A plain static page: no JavaScript, no external requests, no cookies, no tracking.
