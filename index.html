How they are built

  • Zero dependencies. Python's standard library only.
  • Read-only by default. When a tool can change something it previews first, keeps a backup or writes a copy, and never deletes on its own.
  • Honest about limits. These are checks, not oracles: a clean result means "nothing found", never "proven safe".
  • Private by construction. No telemetry and no accounts; tools that must use the network only talk to hosts you name.
